# AVGN 8-bit — порт для Android

> **English summary.** `android/` is the Android port of *Angry Video Game Nerd 8-bit*. It is the same
> **Butterscotch** runtime (AGPL-3.0) that the PS Vita port in this repository uses, rebuilt with the NDK for
> arm64-v8a and armeabi-v7a and driven by Jetpack Compose: touch controls with a full layout editor, game import
> from a folder or a zip, and a launcher that speaks English and Russian. The game files are never shipped: the app
> reads your own copy of the game and builds `data_vita.win` on the device. Download: the `latest-build` release.

Порт игры *Angry Video Game Nerd 8-bit* на Android на базе свободного рантайма **Butterscotch**
(AGPL-3.0) — того же, что использован в PS Vita-порте в этом репозитории. Рантайм собран NDK под
`arm64-v8a` и `armeabi-v7a`, интерфейс — Jetpack Compose.

В APK **нет файлов игры**. Приложение запускает вашу собственную копию: вы один раз указываете папку
с игрой (Steam → «Управление» → «Просмотреть локальные файлы»), приложение копирует нужные файлы в
своё хранилище, собирает из них `data_vita.win` и запускает игру.

---

## Язык интерфейса

Лаунчер, меню паузы и редактор раскладки переведены на **английский и русский**. Тексты лежат в
`app/src/main/res/values/strings.xml` (английский, язык по умолчанию) и `app/src/main/res/values-ru/strings.xml`
(русский); приложение берёт язык из системных настроек, а на Android 13+ язык можно выбрать отдельно для
приложения в настройках системы (`res/xml/locales_config.xml`).

Добавляя новую строку, заведите её в обоих файлах с одинаковым `name`: раскладка `values/` — это то, что
увидят все, у кого язык не русский, а `values-ru/` — русский перевод.

## Что внутри

| | |
|---|---|
| `android/app` | Kotlin + Jetpack Compose: экраны, сенсорное управление, редактор раскладки, GL-поток |
| `android/native` | CMake-сборка рантайма Butterscotch (`runtime/`) под NDK |
| `runtime/` | исходники рантайма (форк Vita-порта) + FreeType + Box2D + miniaudio |
| `android/app/src/main/assets/data_vita.patch` | дифф `data.win → data_vita.win` из Vita-версии (568 КБ) |
| `android/app/src/main/kotlin/ru/avgn8bit/BundledGame.kt` | распаковка файлов игры, вложенных в APK (опционально) |
| `android/app/src/main/assets/shaders` | шейдеры финального блита и CRT-фильтра |

Патч — это не копия игры, а список «скопировать N байт из такого-то места data.win» + вставки.
Он собирается на телефоне за несколько секунд и проверяется: размер источника должен совпасть,
результат обязан начинаться с `FORM` (тег GameMaker-а). Если игра обновилась и не подходит —
приложение не ломает файлы, а запускает игру без патча и предупреждает об этом.

## Сборка

Нужно ровно три вещи:

* **JDK 17**
* **Android SDK** с `platforms;android-35` и `build-tools;35.0.0`
* **NDK 27.0.12077973** и **CMake 3.22.1**

### Android Studio

Откройте папку `android/` как проект, дождитесь синхронизации Gradle и нажмите Run. Всё остальное
(NDK, CMake) Studio предложит доустановить сама — версии уже прописаны в `app/build.gradle.kts`.

### Командная строка

```bash
cd android
sdkmanager "platforms;android-35" "build-tools;35.0.0" "ndk;27.0.12077973" "cmake;3.22.1"
./gradlew assembleDebug        # debug-сборка
./gradlew assembleRelease      # release, подписан debug-ключом, чтобы APK ставился «из браузера»
```

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`
(для release — `.../apk/release/app-release.apk`).

Первая сборка долгая: качаются Gradle и зависимости, а рантайм (Box2D, FreeType, miniaudio)
компилируется под две ABI — `arm64-v8a` и `armeabi-v7a`.

### GitHub Actions

`.github/workflows/android.yml` собирает APK на каждый push и по кнопке *Run workflow*.

Скачать готовый APK проще всего из **Release** `latest-build`: каждая удачная сборка заменяет его
ассеты, поэтому ссылка всегда одна и не протухает:

* `https://github.com/Player124413/avgn-8bit-vita/releases/tag/latest-build`

Там лежат `AVGN8bit-release.apk` (подписан debug-ключом, ставится «из браузера») и
`AVGN8bit-debug.apk`. Для сборки с игрой внутри имена получают суффикс `-bundled` / `-bundled-videos`.
Копии остаются и в артефактах запуска: **Actions** → нужный запуск → **Artifacts** → `AVGN8bit-apk`
(артефакты живут ограниченное время и требуют входа в GitHub, поэтому release удобнее).
Публикация релиза `v*` тоже прикладывает к нему APK.

## Первый запуск

1. Установите APK, откройте приложение.
2. «Выбрать папку игры» **или** «Выбрать ZIP-архив с игрой» — что удобнее.
   Приложение само найдёт нужный уровень вложенности: можно указать папку Steam, саму игру, папку
   `AVGN8bit` из Vita-патчера или zip с любым из них.
3. Приложение копирует `data.win`, шрифты `*.ttf`, папки `Lang`, `Attract`, `Cutscenes` и собирает
   `data_vita.win`. Прогресс виден на экране.
4. «ИГРАТЬ».

Катсцены — самая тяжёлая часть (несколько сотен мегабайт). Переключатель «Копировать катсцены» в
импорте позволяет их пропустить: игра не падает, а просто пропускает ролики (видео-бэкенд в этой
сборке отключён намеренно — как и в Vita-версии, где требовался ffmpeg).

Файлы живут в приватном хранилище приложения (ничего не нужно разрешать):
`files/avgn` — игра, `files/saves` — сохранения, `files/logs` — логи.

## Импорт из ZIP

Архив можно просто скинуть в «Загрузки» телефона и выбрать его в приложении — распаковка идёт сразу в
хранилище приложения, одним проходом, без промежуточной копии (важно, когда в архиве катсцены и он
весит 1–2 ГБ).

Что приложение берёт из архива:

* `data.win` **или** уже пропатченный `data_vita.win` (последний берётся как есть, патч тогда не
  нужен);
* шрифты `*.ttf` / `*.otf` из корня папки игры;
* папки `Lang`, `Attract`, `Cutscenes` (регистр не важен).

Всё остальное (exe, dll, `*.yy`, `__MACOSX`) игнорируется, `..` в путях отбрасывается. Если катсцены
не нужны — выключите «Копировать катсцены», и mp4 не будут распакованы вообще.

## Сборка «игра внутри APK»

Если не хочется возиться с импортом на телефоне, файлы игры можно вложить в сам APK. Они попадут в
`assets/game`, а при первом запуске приложение один раз распакует их в своё хранилище и дальше
работает как обычно.

**Локально:**

```bash
cd android
./gradlew assembleRelease -PbundleGame=/путь/к/game.zip
# или папкой:
./gradlew assembleRelease -PbundleGame="/путь/к/AVGN 8-bit"
# вместе с катсценами:
./gradlew assembleRelease -PbundleGame=game.zip -PbundleVideos=true
```

**В GitHub Actions:** вкладка **Actions** → «Android APK» → **Run workflow**, в поле
`game_zip_url` — прямая ссылка на архив, при необходимости отметьте `include_videos`. Сборка скачает
архив, соберёт APK и положит его в артефакты запуска (`AVGN8bit-release-bundled.apk`, или
`...-bundled-videos.apk`) и в release `latest-build`. В репозиторий архив не попадает: он живёт только
внутри запуска.

Если вы форкаете репозиторий и держите его **приватным**, можно и просто положить архив в
`android/game.zip` и запустить workflow — он подхватит файл из чекаута (`.gitignore` его не пускает,
так что нужен `git add -f android/game.zip`).

Где взять ссылку: подойдёт любой прямой хостинг — release asset **в приватном** репозитории
(публичный release с игрой = публичное распространение чужого контента), свой сервер, S3 с presigned
URL. Ссылка должна отдавать файл по GET без авторизации.

О чём стоит помнить:

* **Размер.** `data.win` — около 170 МБ, катсцены — ещё сотни мегабайт или гигабайты. Обычный APK
  больше 2 ГБ может не установиться на части устройств, а Google Play такие сборки не примет вовсе.
  Поэтому катсцены по умолчанию **не** вкладываются.
* **Лицензия.** Сам код порта — AGPL-3.0, но игра вам не принадлежит. Собранный «всё в одном» APK
  нельзя выкладывать в общий доступ — только для личного использования.
* **Время.** Первый запуск такого APK дольше обычного: распаковка 170 МБ + сборка `data_vita.win` —
  на телефоне это десятки секунд, с прогрессом на экране загрузки.

## Сенсорное управление

Раскладка — это JSON-документ: список элементов, у каждого нормированная позиция (0..1), размер как
доля короткой стороны экрана и список того, что он отправляет игре. Раскладки для ландшафта и
портрета хранятся отдельно.

**Что можно делать в редакторе** (главный экран → «Сенсорное управление», или в игре меню «II» →
«Управление»):

* таскать элементы пальцем (с шагом 2 % — включается «сетка»);
* менять размер, прозрачность и надпись кнопки (до 6 символов);
* форма кнопки: круг / скругление / квадрат;
* добавлять и удалять элементы, дублировать, менять пресет целиком;
* назначать на элемент сразу несколько действий: кнопки геймпада, оси ±, клавиши клавиатуры.

Один элемент может отправлять и кнопку геймпада, и клавишу одновременно — так кнопки работают в игре
в любом случае, независимо от того, что она слушает. По умолчанию: D-Pad + A (прыжок) + B (стрельба)
+ X (предмет) + Start + Select.

Пресеты: «AVGN — 3 кнопки», «NES — 2 кнопки», «Стик + кнопки», «Пустая».

Редактор показывает раскладку той ориентации, в которой вы держите телефон: поверните его в ландшафт,
настройте кнопки, потом поверните в портрет и настройте отдельно. В игре то же самое — меню «II» →
«Управление».

Касания обрабатываются одним обработчиком на все пальцы: мультитач, скольжение большого пальца с
одного направления D-Pad на другое и диагонали работают. D-Pad и стик дополнительно отдают левую
аналоговую ось (`emitAxes`), так что подходят и для игр, которые читают только стик.

Сенсорные кнопки работают вместе с физическим геймпадом и клавиатурой — их можно подключить
одновременно.

## Настройки

* **Графика**: пиксели / сглаживание / CRT (шейдер с изгибом, масочкой и виньеткой), целочисленное
  масштабирование, широкоэкранный режим (больше поля по краям), счётчик FPS, оптимизации Vita.
* **Управление**: прозрачность и размер кнопок, вибрация и её сила, показ кнопок.
* **Экран**: ориентация (ландшафт / по датчику / портрет / как повёрнут), не гасить экран,
  скрывать системные панели.
* **Файлы**: импорт видео, лог (можно отправить себе через любое приложение).

«Оптимизации Vita» включены по умолчанию: это пути рендера, добавленные в Vita-порте (кэш текстур,
непрозрачные батчи, запекание, палитровые шейдеры). Если на конкретном устройстве что-то рисуется
неправильно, выключите — приложение создаст рядом с `data.win` файлы-маркеры `nocrtbake`, `noopaque`,
`notexcache` и т.д., которые рантайм понимает.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Игра не запустилась» | Меню «Логи» в игре или Настройки → «Поделиться логом». Чаще всего не совпала версия игры. |
| Игра запускается без патча (жёлтое предупреждение) | Ваш `data.win` не совпал по размеру с патчем. Проверьте файлы игры в Steam («Проверить целостность»), импортируйте заново. |
| Чёрные/пропавшие спрайты, полосы | Выключите «Оптимизации Vita». |
| Тормозит | Выключите CRT, включите «Пиксели», уменьшите разрешение экрана/герцовку устройства. |
| Нет звука | Проверьте, что не включён беззвучный режим; звук идёт через OpenSL ES. |
| Кнопки мешают | В игре меню → «Скрыть кнопки», или уменьшите их размер/прозрачность. |
| «В архиве нет data.win» | В zip лежит не папка игры. Нужен архив, внутри которого есть `data.win` (можно во вложенной папке). |
| Первый запуск bundled-версии долгий | Это распаковка вложенных файлов и сборка `data_vita.win`; прогресс виден на экране. Второй запуск обычный. |

Логи: `Настройки → Поделиться логом` (в нём и лог приложения, и вывод рантайма).

## Технические заметки

* Рантайм собирается как `libavgn8bit.so`, JNI-класс — `ru.avgn8bit.Native`
  (`runtime/src/android/main.c`). Игра рисуется в FBO, который Kotlin отдаёт в `startRunner`;
  финальный блит и CRT — отдельные шейдеры (`assets/shaders`).
* Один GL-поток, EGL-контекст живёт дольше окна: уход в фон не перезапускает игру, только
  приостанавливает звук.
* Видео (`video_play`) играет системный `android.media.MediaPlayer`: он же разбирает контейнер,
  декодирует H.264 на аппаратном декодере и проигрывает звуковую дорожку. Кадры идут в
  `SurfaceTexture`, а бэкенд (`src/video/android/video_android.c`) рисует их во FBO игровой
  поверхности обычным шейдером `GL_TEXTURE_EXTERNAL_OES` — дальше игра работает с ней как с любой
  другой поверхностью. Поэтому отдельного аудиопотока у видео нет: звук уже в MediaPlayer.
  Ролики берутся из `Cutscenes/` (`Cutscenes/HD/*_1080.mp4` в оригинале): перекодирование в 960x544,
  которое делает Vita-патчер, на Android не нужно — он декодирует полное разрешение.
* Шрифты грузятся FreeType (`font_add`), поэтому нужны `Silver.ttf`, `LanaPixel.ttf`,
  `Probly8-CJK.ttf` из папки игры.
* Патч (`data_vita.patch`) — `AVGNDP01`: заголовок 40 байт, дальше zlib-поток операций
  `'C' + u64 смещение + u32 длина` / `'A' + u32 длина + байты` / `'E'`. Разбор — в
  `GameDataPatcher.kt`.
