# Ключ подписи APK / APK signing key

`avgn8bit-update.p12` — ключ, которым подписываются **все** сборки порта: и debug, и release, и собранные CI,
и собранные локально.

## Зачем он в репозитории

Android ставит обновление поверх установленного приложения только тогда, когда у нового APK та же подпись, что у
старого, и `versionCode` не меньше. Если подписывать каждую сборку свежим debug-ключом (так делает
`signingConfigs.debug` когда `~/.android/debug.keystore` ещё нет), любое обновление требует
«удалить приложение» — а вместе с ним уходят импортированные файлы игры.

Поэтому ключ здесь один на все сборки. Он **публичный**: пароль ниже знает любой, кто открыл этот файл. Это
нормально для фанатского порта, который раздаётся APK-файлом: подпись здесь нужна не как защита, а как
«опознавательный знак» для системы обновлений. Не используйте этот ключ нигде, кроме этого порта.

| | |
|---|---|
| Файл | `android/keystore/avgn8bit-update.p12` (PKCS#12) |
| Alias | `avgn8bit` |
| Пароль хранилища | `avgn8bit` |
| Пароль ключа | `avgn8bit` |
| Алгоритм | RSA 2048, SHA-256, срок до 2056 года |
| Отпечаток SHA-256 | `04:6A:14:FB:97:59:01:AE:1F:BD:18:E4:D0:9C:67:5B:DD:10:AF:DC:70:A1:EA:12:4E:7C:4F:BE:0B:FD:B5:6B` |

Посмотреть отпечаток у готового APK:

```bash
$ANDROID_HOME/build-tools/35.0.0/apksigner verify --print-certs AVGN8bit-release.apk
```

CI дополнительно сверяет отпечатки debug- и release-APK между собой: если они разойдутся, сборка упадёт, потому что
такой APK больше не установится поверх предыдущего.

## Свой ключ

Если вы публикуете свою сборку и не хотите брать этот ключ, подставьте свой — параметрами Gradle, ничего не меняя в
репозитории:

```bash
./gradlew assembleRelease \
  -Pkeystore=/path/to/my.p12 -PkeystorePassword=... -PkeyAlias=my -PkeyPassword=...
```

Пользователям такой сборки всё равно придётся один раз удалить приложение: подпись сменилась.

## Как пересоздать (не нужно, если ключ уже есть)

```bash
openssl req -x509 -newkey rsa:2048 -sha256 -days 10950 -nodes \
  -keyout key.pem -out cert.pem -subj "/CN=AVGN 8-bit Android port/O=avgn8bit/C=RU"
openssl pkcs12 -export -name avgn8bit -inkey key.pem -in cert.pem \
  -out avgn8bit-update.p12 -passout pass:avgn8bit
```

Не пересоздавайте ключ, пока у кого-то установлен порт: новая подпись сломает обновления всем.
